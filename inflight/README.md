# Red Warden In-Flight

In-Flight is an OBS Studio plugin that adds an **In-Flight** dock: a live watchdog that keeps an eye on your stream while you are on air. It is built to be read at a glance, with a row of lights rather than sentences. It never draws anything into your program output.

Part of Red Warden Stream Kit, alongside Red Warden Multistream and Red Warden Pre-Flight.

## Install

Install it with the Red Warden Stream Kit installer, then open **Docks > In-Flight** in OBS.
